# Week 13: Sister's Photography Portfolio

**Posted:** ~1 month ago  
**Impressions:** 4,064 ⭐ TOP PERFORMER  
**Project:** saffronphotos.com

---

When my sister told me that hosting her photography portfolio on Squarespace would cost $300 a year, I knew what I was doing this weekend!

A few hours later, we had a fully deployed website up and running - only paying for the domain. I remember how long it used to take to write HTML in college, let alone make anything look decent with CSS. The fact that we can do that in ~90 minutes still feels a bit surreal.

One practical takeaway from this week's build: I've been overusing Opus.

It's great for planning, but it can be overkill for a lot of the actual build (and it burns through credits fast). This week I tried using Sonnet for all of the little CSS clean up tweaks I wanted to make. Next week I'll push this further and try Sonnet for everything except initial planning. Excited to report back!
