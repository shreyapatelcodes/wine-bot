# Week 8: Personal Website Design

**Posted:** ~2 months ago  
**Impressions:** 1,276  
**Project:** Personal website with AI design tools

---

Here's what I wish someone had told me before using AI for design:

With code, specificity is your best friend. I've learned that when I describe exactly what you want, how it should behave, what the edge cases are, Claude can get 80% of the way there in one shot.

I assumed design worked the same way. So I wrote a 1,274-word prompt for my personal website - hex codes, illustration style references, hover states, the works.

The result was muddy. Too much context, too many competing instructions. And worse, I couldn't change it. Every time I tried to push the design somewhere new, the tool snapped back to the original spec. I'd given it so much context that there was no room left to explore.

So I started fresh with one paragraph that asked Make to create something that feels like a gallery, showcases my personality, features the following sections, and attached my resume and some links.

What came back had animations and a floating nav I never would've thought to ask for. The best design decisions came from things I didn't specify. This time the process was actually iterative. I could ask for one major change at a time (color scheme, layout, sizing) without the whole thing collapsing.

New rule: prompt code like an engineer. Prompt design like a creative director - set the vision, then get out of the way.
