# Week 14: First Skill File

**Posted:** ~3 weeks ago  
**Impressions:** 1,186  
**Project:** Skill file for Google Docs formatting

---

This week I made my first skill file. 14 weeks into my quest of building and shipping weekly with AI. I know. 

This week was scattered. I did some design cleanup on my sister's photography site, fixed a bug in my email agent that had been sending forwarded emails as blank messages with just a subject line (it had been doing this for weeks), and used Claude's new insights feature to look at how I've been building. 

This week as part of my APM program at LinkedIn Lauren Charney led a workshop about building with AI and she casually mentioned she has a folder of dozens of skills. 

For anyone who doesn't know, a skill file is basically a little instruction sheet - like the ones you'd get in elementary school - that tells Claude exactly how to do a specific task. 

Lauren uses them to spin up prototypes, run data analysis, format docs. I've been using AI almost every day, and never made a single one. 

So I spent 10 minutes making my first one. It formats Google Docs so that when I write a PRD I'm not spending 10 minutes fixing the headers and spacing before I can actually use it. Embarrassingly simple. Embarrassingly useful! 

The thing I keep coming back to is how easy it was. 10 minutes to never think about that again.
